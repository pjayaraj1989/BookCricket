# Stadium images

Drop stadium photos in this directory and the web UI's event pane will show
the ground when the venue is selected at match setup.

## Filename convention

Same rule as everywhere else in resources/: lowercase the venue name exactly
as it appears in `data/venue_data.json`, replace every run of
non-alphanumeric characters with a single underscore, and add an image
extension. Supported extensions: `.png`, `.jpg`, `.jpeg`, `.webp` (checked
in that order). Images are shown at up to 150x95, cropped to fit, so
landscape shots work best.

If no image is found for a venue, the UI falls back to a stadium emoji, so
add only the grounds you care about.
