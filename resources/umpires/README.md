# Umpire pictures

Drop umpire photos in this directory and the web UI's event pane will show
the two match umpires side by side when they are announced at match setup.

## Filename convention

Same rule as player pics: lowercase the umpire's name exactly as it appears
in `data/resources.py`, replace every run of non-alphanumeric characters
with a single underscore, and add an image extension. Supported extensions:
`.png`, `.jpg`, `.jpeg`, `.webp` (checked in that order). Square-ish images
work best - the UI crops them into a 72px circle.

If no picture is found for an umpire, the UI falls back to an initials
avatar, so missing pictures are fine.
